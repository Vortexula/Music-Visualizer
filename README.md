# Music-Visualizer

This is my first Git project! It is a web-based visualizer entirely client-side through AudioContext API and Butterchurn (WebGL & Milkdrop API Fork.) There are currently 5 visualizers: Bars, Wave, Circular, Butterfly, and Butterchurn. To use the visualizer just go to the link on my Github and upload a music file, then choose a visualizer you'd like to see!
